# Introduction to Cyber Security

Cybersecurity is the practice of protecting systems, networks, and data from unauthorized access, attacks, or damage.

In today's digital world, almost everything relies on computer systems and internet connectivity. Because of this, organizations must protect their infrastructure from attackers.

---

# Why Cyber Security is Important

Modern organizations store huge amounts of sensitive data such as:

* User credentials
* Financial data
* Personal information
* Company secrets

Attackers target these systems to:

* Steal information
* Gain unauthorized access
* Disrupt services
* Spread malware

Example real-world attacks include:

• Data breaches
• Ransomware attacks
• Website defacement
• Distributed Denial of Service (DDoS)

---

# The CIA Triad

The foundation of cybersecurity is based on three core principles known as the **CIA Triad**.

```
Confidentiality
Integrity
Availability
```

These three concepts guide how secure systems should be designed.

---

# Confidentiality

Confidentiality ensures that sensitive information is only accessible to authorized users.

Example:

A database containing user passwords must not be accessible to unauthorized people.

Common protection methods include:

* Authentication
* Encryption
* Access control

Example attack:

If a hacker steals a company database, **confidentiality is broken**.

---

# Integrity

Integrity ensures that information cannot be modified without authorization.

Example:

Imagine a bank transaction:

```
Original amount: $100
Modified by attacker: $10,000
```

If attackers modify data without permission, integrity has been compromised.

Protection methods include:

* Hashing
* Digital signatures
* File integrity monitoring

---

# Availability

Availability ensures systems remain accessible when needed.

Example:

If a website is down, legitimate users cannot access it.

One common attack affecting availability is:

```
DDoS Attack
```

In this attack, thousands of machines flood a server with traffic until it crashes.

---

# Types of Hackers

Hackers are generally classified into three categories based on their intentions.

---

## White Hat Hackers

White hat hackers are ethical hackers who test systems to improve security.

Examples of roles:

* Penetration Tester
* Security Researcher
* Red Team Operator

They identify vulnerabilities before malicious attackers exploit them.

---

## Black Hat Hackers

Black hat hackers are malicious attackers who exploit systems for personal gain.

Examples include:

* Ransomware operators
* Data thieves
* Cyber criminals

---

## Grey Hat Hackers

Grey hat hackers operate between ethical and malicious hacking.

They might find vulnerabilities without permission but disclose them later.

Although intentions may not be harmful, their actions are still unauthorized.

---

# Cyber Security Domains

Cybersecurity can be divided into two major domains.

```
Offensive Security
Defensive Security
```

---

# Offensive Security

Offensive security focuses on **simulating attacks** to find vulnerabilities.

Professionals in this field include:

* Penetration Testers
* Red Team Operators
* Bug Bounty Hunters

Their goal is to identify weaknesses before attackers do.

---

# Defensive Security

Defensive security focuses on **detecting and preventing attacks**.

Professionals in this field include:

* SOC Analysts
* Security Engineers
* Incident Responders

Their job is to monitor systems, detect attacks, and respond to security incidents.

---

# Key Takeaways

Cybersecurity protects digital systems from attacks.

The core principles are:

```
Confidentiality
Integrity
Availability
```

Cybersecurity includes two major domains:

```
Offensive Security → Attack simulation
Defensive Security → Attack detection
```

Understanding these fundamentals is essential before learning advanced topics such as web exploitation and penetration testing.
