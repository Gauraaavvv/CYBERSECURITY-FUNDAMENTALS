# Defensive Security

Defensive security focuses on **protecting systems, detecting attacks, and responding to security incidents**.

While offensive security simulates attacks to find vulnerabilities, defensive security focuses on **monitoring systems and stopping attackers**.

Professionals working in defensive security are often referred to as the **Blue Team**.

---

# Goals of Defensive Security

The primary objectives of defensive security include:

• Prevent cyber attacks
• Detect malicious activity
• Respond to security incidents
• Protect sensitive data

Organizations rely heavily on defensive security teams to monitor their infrastructure and maintain system security.

---

# Blue Team

The **Blue Team** is responsible for defending an organization against cyber attacks.

Their responsibilities include:

* Monitoring network traffic
* Analyzing system logs
* Detecting suspicious activity
* Responding to incidents
* Improving security defenses

---

# Security Operations Center (SOC)

Many organizations operate a **Security Operations Center (SOC)**.

A SOC is a centralized team responsible for monitoring and responding to security threats.

Typical SOC activities include:

* Log monitoring
* Incident detection
* Threat investigation
* Security alert management
